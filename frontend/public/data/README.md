# Data: výročí z české Wikipedie

Soubory `MM-DD.json` obsahují texty událostí ze stránek dnů české Wikipedie
(např. „28. říjen“). Autoři: přispěvatelé Wikipedie. Licence:
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.cs).

Každá karta nese odkaz na konkrétní revizi zdrojové stránky (`source.revisionUrl`), na historii
s autory (`source.historyUrl`) a čas načtení. Texty jsou převzaté beze změny obsahu (odstraněny
jen reference a formátování). Licence zdrojového kódu projektu se na tato data nevztahuje.
